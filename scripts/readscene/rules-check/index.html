Link Rules Check

The editor draws nodes moving as links are stepped. A drawing can be faked, so this page sets the drawing aside. It takes the numbers the editor saved and recomputes every position from six written rules. The code here is its own, written from the rules, and none of it comes from the editor. All of it is shown at the bottom of the page.

The loaded data is the editor's own export of all six sequences, taken on 2026-10-31 with go run ./scripts/readscene -json topology-pair-phi-theta-3 and kept in scene-export.js beside this page. Edit any number, or paste your own export, and press Check.

The rules

For a link, s is the s of the node it goes to, and one turn is T = 12·s ticks.

  1. Where a link points. φ = start φ + Δφ and θ = start θ + Δθ, each wrapped into 0 ≤ angle < T. r = start r + Δr.
    The code for this rule
    2. 
      
  2. A step. It adds the increment, plus or minus, to one Δ (φ, θ or r), or with the "both" button to all three, and changes nothing else in that link. An angle's Δ is wrapped into 0 ≤ Δ < T; Δr is not. A step that would take r below 0 is refused.
        
    The code for this rule
    3. 
      
  3. A link's vector. With a(t) = t · 2π / T:
        x = r·ρ·sin a(φ)·cos a(θ)
y = r·ρ·cos a(φ)
z = r·ρ·sin a(φ)·sin a(θ)
        One case differs: when φ > T/2 and φ = θ, z is negated. There both angles count as negative, and without the flip sin φ · sin θ would be a square that never lets the link reach the negative-z side.
        
    The code for this rule
    4. 
      
  4. A node's position. The same formula, with r · constant-r for the length, φ · 2π / max-index-φ and θ · 2π / max-index-θ for the angles, and no z flip.
        
    The code for this rule
    5. 
      
  5. Every link closes. For every link a→b, position(a) + vector(a→b) = position(b), to floating-point rounding.
        
    The code for this rule
    6. 
      
  6. What a step of the selected links changes. Each Δ of a stepped link that changes changes by exactly its increment (wrapped, as in rule 2), and the link's start stays the same. No other link's Δ changes. A link that was not stepped but touches a node that moved gets a new start, the one that makes rule 5 hold for it again.

Rules 1–5 are checked on one state. Rule 6 needs a before and an after. scene-steps.js holds 48 of them: each of the eight step buttons pressed once on each sequence by the same link code the editor runs, run outside the editor with go run ./scripts/readscene -steps topology-pair-phi-theta-3. All 48 are checked when the page opens, and any one can be loaded below.
