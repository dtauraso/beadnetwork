Link Rules Check

The editor draws nodes moving as links are stepped. A drawing can be faked, so this page sets the drawing aside and checks the numbers instead. Three separate things are involved:

  • The rules are seven statements in words, below and in summary_how_it_works.md. They are not code.
  • The editor is Go. It applies the rules and made every number in data/, run outside the editor by scripts/readscene. Under each rule is the Go function that does it.
  • This page's checker is JavaScript in rules-check/rules/, written from the words alone. It is not a port of the Go: it sends no messages between nodes and never works angles back out of positions, as the editor does. It only predicts what the words say should happen and compares that with the numbers the Go recorded.

The loaded data is the export of all six sequences, taken on 2026-10-31 with go run ./scripts/readscene -json topology-pair-phi-theta-3 and kept in data/scene-export.js. Edit any number, or paste your own export, and press Check.

The rules

Each rule is followed by where the editor's Go does it, under Categories/Node/Links/, and then, folded away, the JavaScript this page uses to check it. Click a Go function to open its file as a tab in VS Code, at the function. Which file each function is in comes from go run ./scripts/readscene -source Categories/Node/Links, kept in data/go-source.js. The click works in Live Preview with the topology extension running: the extension listens on localhost and writes its address to port.js beside this page.

  6. What a press changes. A press steps one link into each node: the first selected one, in saved order. That link's Δ changes as rule 2 says and its start stays. No other link's Δ changes. A node reached by a stepped link moves to position(from) + vector(link) with the new Δ; every other node stays where it was.     7. 
      
  7. The order of presses does not change Δ. Steps add whole-number increments to Δ, and addition does not depend on order, so φ+, θ+ and r+ in any of their six orders leave every link with the same Δ. A link that was not stepped can get a new start, worked out again from where the nodes moved to; that never changes its Δ.

Rules 1–5 are checked on one state. Rule 6 needs a before and an after. data/scene-steps.js holds 48 of them: each of the eight step buttons pressed once on each sequence, made with go run ./scripts/readscene -steps topology-pair-phi-theta-3. Rule 7 uses data/scene-orders.js, made with -orders: the six orders of φ+, θ+ and r+ on every sequence. Both files start in the Runs box below, where every run is checked against rule 6 and every group of runs pressing the same buttons in different orders against rule 7. Any run can be edited there, or replaced with your own -steps or -orders output, and any one can be loaded into Before and After.
