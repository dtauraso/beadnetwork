3 Move central edge-curve emitter into per-goroutine emission Done. Each edgeMover goroutine (node_move.go) emits its own edge geometry (tr.Geometry) on every node-move that touches either endpoint. The loader no longer has a central curve-emit loop. DONE
4 Route node-move to the owning node/edge goroutine Done. applyNodeMove and NodeMoveRegistry are gone. The loader builds a MoveDispatch — a pure key→inbox-channel registry keyed by BOTH node ids AND edge ids. The stdin reader mail-sorts each (key,value) entry from a node-move message onto channels[key]; no recompute lives in the reader. Each nodeMover goroutine owns one node's geometry and re-emits its own node-geometry on a move. Each edgeMover goroutine owns one edge: on a move of either endpoint it recomputes its own segment/arc, writes them onto the source Out, revises any in-flight bead via ReviseInFlightGeometry, emits its own edge geometry, and updates the dest port's MaxIncomingSimLatencyMs aggregate. Fade also routes through MoveDispatch: each edgeMover calls SetFaded on its own PacedWire — no central fan-out. DONE
