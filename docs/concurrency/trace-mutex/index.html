Trace.mu — the record of a question that closed

This page used to describe Trace.mu as present and its removal as open. It is now deleted — the seventh and last sync.Mutex/Cond in non-test Go. All six others were already deleted before it: geomMu deleted, RealClock.mu deleted, PacedWire.mu deleted, outbox.mu deleted, LayoutHolder.mu deleted, debouncedPersister.mu deleted. Its stated job was guarding the event accumulator, and that claim was true but vestigial — nothing in production ever raced it. What the lock was actually still doing — serializing Breadcrumb's direct sink writes and surviving a shutdown that didn't wait — is what got fixed.
