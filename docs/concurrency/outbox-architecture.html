outbox.mu — the record of a question that closed

geomMu was removed, LayoutHolder.mu was removed (LayoutHolder itself was later deleted entirely), and PacedWire.mu was removed — each was called necessary first. This page argued outbox.mu was the fourth and still standing. It is now gone too: task/mutex-outbox-restructure deleted the outbox struct entirely — no queue, no mu, no cond, no dedicated sender goroutine, no ctx-watcher goroutine. What's below is kept as the argument that led there, not as a description of the code that runs today (see diagram 6 for that).
