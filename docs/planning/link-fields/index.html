Two structures: A link: Data structure 1: a link

Data structure 1: a link

A link is a tracking head: where that connection is right now. It holds START (whole ticks plus 1/s parts, at the link's s) and Δ sum, and nΔ, how far one press moves an amount on each axis (as Link.Increment does today, set with the nΔ stepper), and a direction set, which way a both press moves each axis (today's Lock), and Way, the sign its Δ sum had at the last press, which tells remeasure which (φ, θ) pair to keep. Nothing about steps.
