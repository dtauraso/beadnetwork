A Scope bar. Where you are (sequence breadcrumb), the one sequence-wide number (s), and doors to the rarely edited scopes. Frame says reloads scene before you open it.

B Score. All the step × link cells at once, grouped by target node. The highlighted column is the step shown in the scene. See Score.

C Inspector. Edits the one selected cell: pick switch, φ/θ dials, r ruler, Δ / nΔ / total kept apart and labeled. See Inspector.

D Status strip. The human tick, the slowest node, and whether anyone is behind, plus the keys that work right now.
