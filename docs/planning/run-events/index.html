Data structure 2: the UI

A run

A run plays the leaf steps in order, each with all the edges picked for it and their amounts (φ, θ, r). The run holds one number, the counter, which names the leaf step it is playing: 1 is step 1.1, 2 is step 1.2, 3 is step 2.1. Before the first, the run sets every link's Δ sum to 0 and leaves START as it is, so each link is drawn at its START until a step moves it. Then it plays the leaf step the counter names, over ×N ticks, sends a settle round (below), and adds 1 to the counter once every node has reported it. A run counts through every leaf step in order, then stops. During a run nothing can be edited. A step has no ▶ of its own: ▶ run is the one play button.
