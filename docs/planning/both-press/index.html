Data structure 2: the UI

The both press

A both ± press moves φ, θ and r together, each by its link's nΔ. Each axis goes the way its direction set says (↑ or ↓): the link's first, then the step's, and + if neither is set. both − goes the other way on every axis. Each amount it changes is sent, like any change. A press on a leaf step's head reaches every edge picked in that step (below).
