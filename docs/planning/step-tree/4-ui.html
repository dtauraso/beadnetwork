Links tab UI standard · one tree: one way to fold, to go in, to come back out, and to act

The Links tab is a tree, and it follows the tree everyone already knows, VS Code's Explorer: one kind of row, a chevron to fold, indentation for depth, one selected row, and actions only on the right. Everything below is one of the elements in the table, and nothing else.

The elements — there are seven

elementlooksdoes
pathone line of plain text at the top, › between levels, the last one darkclick a segment to go back up to that level
rowchevron ›/⌄, name in dark text, detail after it in grey; one size, one weightclick selects it; click the chevron folds it; double-click goes in
selected rowpale blue background, the only highlight on the pageshows that row's actions on the right; arrow keys and F2 act on it
actionsmall white boxed glyph, right edge of the selected row only, always in the order → ✎ + ⧉ ×go in, rename, add after, duplicate, delete
fieldwhite box with dark text; pale blue with a caret while typingclick to type a value, Enter keeps it, Esc drops it
togglewhite boxed label; pale blue when onclick turns it on or off (HEAD φ θ r)

Text is dark #222 or grey #555 on white, 13px, never coloured, never white. Small grey 11px is only for table column heads and HEAD.

The levels

  • Sequences — rows are sequences. Actions: go in, rename, add, duplicate, delete.
  • a sequence — first row is network (what runs now; folds, has no actions), then its steps.
  • a step's own steps — the same as a sequence's level, one deeper. The path shows how deep.
  • Inside an open step: HEAD toggles, then a row per node; inside a node, a row per link; under the picked link, its card.

What this removes from what's built now

  • the sequence dropdown popover, which becomes the Sequences level
  • rename by clicking a name (clicking now only selects), which becomes ✎ / F2
  • grey bands on every step row and on the path, along with blue, green and red text and the bold step titles
  • actions on every row at once; they now appear on the selected row only
  • ▸ ▾ ▶ ▼ mixed glyphs, replaced by one chevron pair
