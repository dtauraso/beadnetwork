Step folders · one folder per step, holding everything about that step

  • To see one step, you have to open three folders: heads/step-1, picks/step-1 and clones/step-1.
  • step/1/ is node 1, while heads/step-1/ is step 1.
  • A pick is stored twice: picks/step-1/2To3.bin and picked.bin in the step's link copy.
  • The list of steps lives in code (step_picks.go:19), not on disk.
  • A step holds the same nodes/<id>/links/<from>To<to>/ layout as the network, so one reader loads both.
  • steps/ is an array indexed by folder name, the same as sequences/ already is.
  • A pick is picked.bin in the step's link folder, and nowhere else.
