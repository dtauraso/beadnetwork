One link, one row

Proposal for the step list. Every node gets an "into node N" header, even when only one link comes in. Then the header is a fold you must open before the one row under it can be clicked, and the header says nothing the row doesn't: "2 → 1" already names node 1. This page proposes drawing a node with one link in as that link's row alone.
