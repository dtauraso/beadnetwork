One-click edge select

Clicking an edge in the network view opens its card in the links tab but does not pick it, so the card is read-only and a second click, on the row, is needed before its numbers can change. If the card was already open, the click closes it instead. This proposes that one click on an edge selects it: picked in the shown step, card open, ready to turn.
