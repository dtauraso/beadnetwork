The model's rules, unchanged, shown where they apply

Nothing here changes what the nodes allow. These are the rules already in the model, and how each looks in the new layout.

One pick into a node, any number out

In a step, a node can have only one picked link coming into it. Picking a second one moves the pick. Links out of one node are into different nodes, so all of them can be picked at once.

Fixed r

A node with two or more links in holds its distance, so r cannot change on any link touching it. The r steppers are dimmed and the card says why.
