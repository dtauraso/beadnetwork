Build

Mostly state that already exists, laid out differently

No model change. The nodes receive the same edits they do today. What changes is the Links tab's own state (in Go) and the layout code that turns it into marks.

State

NeededWhere it is
Which steps are openNew: a set of step numbers on Builder.Model, saved per level like the node folds. Replaces the single ScoreCell.
Which nodes are open in which stepExists: StepFolds map[StepNode]bool, already per step and node.
Which link cards are openExists: CardsOpen map[StepEdge]bool, already a set.
Step in the sceneExists: StepShown().
HEAD locks and pressesExists: StepHead, OpAllLock with a sign (▲▼), and the new OpAllLockCycle for the chip.
Picks, presses, nΔ, start, 1Exists: OpStepPick, OpLinkPress, OpIncrement, OpLinkStart, OpLinkOne.
Dial dragExists: StartTurn/TurnTo/EndTurn; each card's dial is its own spot, so any open card can be dragged.

Code

  • Kept: Categories/Chrome/Panels/Board/ (marks, spots, widgets, the block file and its drawer) and the Sheet hook that lets a pill be a board.
  • Rewritten: Categories/Chrome/Pills/Builder/LinksBoard/: the score grid and inspector files are replaced by a step column, a node row, a link row and a link card, laid out top to bottom inside each column.
  • Rewritten: the Builder files that fill its data (links_score.go, links_inspector.go), from the open sets instead of one selected cell.
  • Changed: clicking an edge in the scene toggles that link's card in the shown step instead of selecting one cell.

Order

  1. Open-steps set on the model; columns with headers, tools and closed strips.
  2. Node rows inside a column, folding through StepFolds.
  3. Link rows and cards through CardsOpen: pick dot, dials, steppers, r ruler, fixed and at-0 notes.
  4. HEAD row with ▲▼ and the cycling chip.
  5. START column.
  6. Scene: edge click toggles a card; hover links row and edge.
  7. Narrow layout. Then build, checks, and a pass comparing every page here against the editor.
