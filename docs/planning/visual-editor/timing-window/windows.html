W is not a fixed config value. It is recomputed from the node's current input edges whenever any input edge length changes (node moved, edge reconnected, midpoint dragged): W = 1.5 × longest current input edge travel time, where travel time = bezier arcLength ÷ 0.08 WU/ms (uniform pulse speed). The values below are a snapshot at the current geometry — they change automatically if geometry changes. This table lists only nodes with a window (≥2 input edges). Single-input nodes (i0, i1) are excluded — they have no window and receive normally.
