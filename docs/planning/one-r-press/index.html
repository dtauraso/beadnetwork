Data structure 2: the UI

The 1r press

START keeps parts finer than a tick, as today: on each axis, a count of 1/s of a tick (Start.One), where s is the link's own (Start.S, set from its node). A 1r press moves that count by one; at s it carries into the tick (StepOne). So START is changed by remeasure and by a 1r press. A 1r press on a leaf step's head reaches every edge picked in that step (below).
