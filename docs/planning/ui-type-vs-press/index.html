Data structure 2: the UI

Deleting a step removes the step from the UI. It sends nothing, so no link changes: a link takes messages from any step and keeps what it was sent. Deleting an amount is a change to an amount, and is sent.

Copying a step sends nothing either: the copy is a new step holding the same amounts, and a copy is not a change to an amount, as today (OpStepCopy clones the column and adds nothing). Its amounts reach the links when a run plays it; any later edit to it is sent.
