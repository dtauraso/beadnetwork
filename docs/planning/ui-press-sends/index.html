Data structure 2: the UI

The UI holds a tree of steps, as the Links pill does today:

  • Leaf step: no steps inside. Holds its own amounts, and one dial per amount: a φ dial and a θ dial for each edge, each showing that amount's change from 0, and r, a length, shown as a number. The dials are drawn on the step's row.
  • Parent step: holds steps, and no amounts.

What reaches a link: every change to an amount is sent.
