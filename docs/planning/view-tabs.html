Links tab: tabs instead of the ⋯ menu

Network, Nodes and Frame already behave as tabs: each one replaces the step cards under the bar, and opening one closes the other two. This plan names them as tabs and gives them their own row at every width, so nothing is left to collapse into ⋯.

  • A tab row under the scope bar, the same at every width: Steps · Network · Nodes · Frame. The open one is lit. Four short labels fit in about 260px, so there is no overflow menu. If the panel gets narrower than that, the tabs wrap onto a second line instead of being cut off.
  • Steps is a tab. Clicking it closes whichever other view is open. Clicking the open tab does nothing; it no longer toggles that view closed.
  • s moves into the Frame card as its first row, next to Δt. Both are timing settings shared by every step, and both apply the moment you type them, so neither waits for Apply.
  • The ⋯ chip and its menu are removed, along with the ▾ on the door labels.

Check in the editor

  • At wide and at narrow width, each tab opens its view and Steps returns to the cards.
  • Typing a new s value in the Frame tab changes the animation speed straight away.
  • The Network view still reopens after "Developer: Reload Window", since it is saved to network-open.bin.
  • Leaving the Frame tab with unapplied edits discards them, as Cancel does today.
