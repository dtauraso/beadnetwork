The step-head press

A press on a leaf step's head reaches every edge picked in that step, and no other, as today (StepHeadEdit, stepActive): a both press changes each picked edge's amounts, each by its direction sets, and they are sent; an nΔ press changes each picked link's nΔ; a 1r press moves each picked link's START 1/s part.
