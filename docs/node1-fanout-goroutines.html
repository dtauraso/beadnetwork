the seam

The decision and the timestamp live in different goroutines

Every other piece of state on this page is written by exactly one goroutine — the one that decides it. A bead's placementTick is the exception: the Input kind decides the bead exists, and the mover stamps its start time whenever it next drains that wire.

Two beads from one broadcastPlace should share a start time by construction. They only do if the goroutine that placed them is the one that stamps them. Moving the stamp into Send closes the split — the sender reads its own clock once and both wires carry it.

bridge

One goroutine, one stream

Each emitting goroutine owns a dedicated pipe to the editor; nothing funnels through a shared writer. The chain beads travel on node 1's own node-stream frame, not on either edge's — they are node-local offsets from node 1's center.
