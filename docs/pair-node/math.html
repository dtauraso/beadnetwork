One quarter turn, sent as is

Both nodes of a pair run this same unmodified rule — a field read off the ring, nothing further is done to it.

separation, folded to the short side

No trig: both states are already on the ring, so the fold is one subtraction against the ring's own half-turn count (separation). This number alone names no resting state — each machine reads its own halt off it, in its own file (Perpendicular).

Every opening, swept

All 576 openings of a 24-point lattice — every starting tilt for node 1 against every starting tilt for node 2 — run through the same decision functions the live node calls, in the order its own loop calls them. The numbers below are produced by that sweep, not estimated; run it with -v after changing the rule and put its new output here.

264 parallel the tilts on one line, pointing OPPOSITE ways

Every one of the 576 settles, and none takes more than 4 rounds — a round being both ends reading the other's last normal and stepping once.

Both of the last two rows ARE parallel — two arrows on one line are parallel whether or not they point the same way, so reversing one changes nothing about the relationship. The rule reads it that way without being told to: its halt is a separation of a quarter turn between this node's top and the arrival, and separation folds the long way round into the short one, so a reversed partner lands exactly where an aligned one does. The split is listed here only because the arrows LOOK different in the editor.
