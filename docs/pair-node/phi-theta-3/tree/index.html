The a→b tree

The a→b builder's data as it is now, drawn as the tree the builder keeps: builder, then its edges (builder.trees, one per row), then the two nodes each edge joins, each box holding that thing's variables. A node two edges share has an arrow from each. Read with the builder's own scripts from what the builder tab last saved in this browser; it redraws when the builder saves. Stored values are plain; values the builder works out from them are not stored: they sit below a dashed line in each box, in italics, and a value that is a reference to another box — a node or an edge, not a copy of it — is green and dotted-underlined.
