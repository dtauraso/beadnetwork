The a→b tree

Editing a→b, by the pairs each part of the move uses, and the builder function that does each part (builder/builder-send.js). The pictures use the three-node example: a→b φ 2 θ 0 r 2, b→c φ 4 θ 0 r 2, a→c a copy, then a→b's φ set from 2 to 3. Each box lists what that tree node holds after the edit, read from the builder's own tree; grey lines are what a node reads from the nodes under it.

root — bMove(st, a→b's tree, was)

One call per a→b edit, on a→b's own tree: every edit in the builder is handed a tree, not a row. It runs the tree's a→b node first, which stores was and now there and places b. Then, for each root of the tree — one per (a→b, a→c) combination, holding that combination's node and its b→c node — it runs bPair, and when c moved, bTurnVia on that root's b→c node with the same rot. Each root also links back to its mirror, the (a→c, a→b) root in a→c's tree, which is how a copy's own tree reaches the pair nodes that rotate it.

a→b — bHead(st, a→b node, was)

b goes to a + the a→b row's frame × (φ, θ, r). Setting φ from 2 to 3 swings b round a by one tick, 30° here (12 ticks a turn, s = 1).

(a→b, a→c) — bPair(st, (a→b, a→c) node) building rot with bStep and bRot

The turn is read off a→b: bPair visits the a→b node for was and now, and whatever turned a→b from was to now is rot. Its own variables — base, ref, held, went, step, own step, automatic — are stored in this node. With own step on, rot is built from was to was + sign(change) × step instead, per φ and θ. rot is stored in the a→c node.

a→c — bRound(st, a→c node)

c = a + rot × (c − a), with rot read from the a→c node. c moves on a circle round a, so |ac| stays the same. Only c moves here; b was already placed by a→b. If a or c has no position, nothing moves and b→c is skipped.

b→c — bTurnVia(st, b→c node, rot)

The row that placed c, here b→c, keeps its φ 4, θ 0, r 2 and has its frame turned by rot instead. Read in the unturned frame, b→c now points at φ 5; in its turned frame it still reads φ 4, so the next time b→c places c it puts c where bRound did.
