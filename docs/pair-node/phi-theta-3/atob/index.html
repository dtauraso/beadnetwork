The a→b and c→b vectors

Node a starts at (1, 0, 0) and node c at (0, 0, 1); the sliders at the bottom move them. Each node turns its own vector in its own view, then each pair computes the new centre globally, last: ba = Ca + polar_to_cart(a→b), bc = Cc + polar_to_cart(c→b).

    a→b — local first, global last

      c→b — local first, global last

        1. One b, three ways to move it. The both sliders move b over the shared sphere; the a→b sliders turn a's vector in a's view, r held; the c→b sliders turn c's vector in c's view, r held. Whichever you move last drives b, and the others read their angles back off it.
        2. Local first. The other node finds where b went by adding two local vectors, no centre used: dca + dab, or dac + dcb. It reads its own r, φ, θ off that, then builds its own vector from them. Both vectors are built the same way: polar_to_cart(r, φ, θ).
        3. Global last. Each pair then draws the new centre from the global centre on its own: O→a + a→b = O→ba, and O→c + c→b = O→bc. Both land on the same b.
