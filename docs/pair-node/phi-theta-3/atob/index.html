The a→b and c→b vectors

Node a is at (1, 0, 0) and node c at (0, 0, 1). The both sliders move one b, and each vector aims at it from its own node. Each pair is its own global calculation: ba = Ca + polar_to_cart(a→b), bc = Cc + polar_to_cart(c→b).

b — shared by both

    a→b — its own calculation, in order

      c→b — its own calculation, in order

        1. The two sliders move one b, on the sphere of radius √2 about O: Φ is measured from +y, Θ round the vertical from +x. Both vectors re-aim at it.
        2. Each vector's own φ and θ are about its own node, so they differ from Φ and Θ and from each other; its r is however far b is from that node.
        3. The two calculations are independent. a→b uses only b and Ca; c→b uses only b and Cc. Neither reads the other's result, so they run in either order, or at once, and give the same numbers.
        4. Each closes its own triangle: O→a + a→b = O→ba, and O→c + c→b = O→bc. Both tips are the shared b, so the two triangles always end at the same point.
        5. From O, each b is read as cart_to_polar(b − O). Those angles are not φ and θ, which are about each vector's own node.
