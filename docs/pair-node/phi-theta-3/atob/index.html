The a→b, c→b and d→b vectors

Node a starts at (1, 0, 0), node c at (0, 0, 1) and node d at (1, 1, 1); the sliders at the bottom move them. Each node turns its own vector in its own view, then each pair computes the new centre globally, last: bn = Cn + polar_to_cart(n→b) for n = a, c, d.

    a→b — local first, global last

      c→b — local first, global last

        d→b — local first, global last

          1. The both box. Ticked, a, c and d share one b: any node's sliders move it and the other two re-aim at it through that node (e.g. ddb = dda + dab), and the both sliders put it on a's and c's shared sphere. Unticked, each pair turns only its own vector, r held, and they can miss.
          2. The a, c, d boxes show or hide a node, its sphere and its lines. The maths runs for all three either way; the shared sphere is drawn when a and c are both shown.
          3. Each builds its own. Whichever way b moves, each node reads its own r, φ, θ and builds its own vector, polar_to_cart(r, φ, θ). Moving a node re-aims only that node's vector by how far it moved, so every gap stays as it was.
          4. The gaps, local. dca + dab − dcb and dda + dab − ddb use no centre. All three globals land on one point exactly when both are zero.
          5. Three spheres. With every r held, b must be on a's, c's and d's spheres at once: a's and c's meet in the shared circle, and d's sphere crosses that circle in at most two points.
          6. Global last. Each pair then draws its new centre from the global centre on its own: O→n + n→b = O→bn.
