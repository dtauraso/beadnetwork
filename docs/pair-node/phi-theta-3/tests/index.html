Builder tests

Each test runs the builder's own scripts (the ones the a→b builder tab loads) through a list of edits, one step at a time, and compares what the step leaves with what the builder left at the same step at commit c1db60fcb — the last builder before the rows moved into the trees. The page runs them each time it opens; a step that differs is marked ✗ and opened, with the differing nodes and rows in red.

One sequence on one builder state, from the three-node preset. Each step compares every node's index (r, φ, θ) and via, and every row's kind and frame (each frame turn compared to 9 places). Numbers match when they are within 10⁻⁹.

Copy directions and saves

The direction each row gives — a copy has one per (a→b, a→c) node rotating it — and where the nodes are, across a save the old builder wrote and a save the tree builder writes. Directions and node positions are compared to 3 places.
