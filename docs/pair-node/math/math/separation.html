One quarter turn, sent as is

Both nodes of a pair run this same unmodified rule — a field read off the ring, nothing further is done to it.

separation, folded to the short side

No trig: both states are already on the ring. The rule does not compute this folded separation at all — it takes a plain abs distance from EACH end (offset) and turns toward whichever is inside a quarter turn. The picture is the geometry; the code is two subtractions and a comparison.
