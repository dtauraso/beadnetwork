Every opening, swept

All 576 openings of a 24-point lattice — every starting tilt for node 1 against every starting tilt for node 2 — run through the same decision functions the live node calls, in the order its own loop calls them. The numbers below are produced by that sweep, not estimated; re-derive and put the new output here after changing the rule.

24 parallel the tilts on one line, pointing the SAME way
552 parallel the tilts on one line, pointing OPPOSITE ways

Every one of the 576 settles, and none takes more than 10 rounds — a round being both ends reading the other's last normal and stepping once.

Both rows ARE parallel — two arrows on one line are parallel whether or not they point the same way, so reversing one changes nothing about the relationship. The rule reads it that way without being told to: it measures a distance from EACH end of the tilt line (offset), so a reversed partner is the other end's distance and lands on the same line. The split is listed here only because the arrows LOOK different in the editor.
