What perpendicular is, and what the node actually sees

The pair is perpendicular when its two TILTS are a quarter turn apart. No node ever receives a tilt, though — what crosses the channel is the partner's COPLANAR NORMAL, which already sits a quarter turn off the partner's own tilt. So the relationship arrives here with a quarter turn already folded into it.

a quarter turn apart separation 0 — the arrival sits exactly on this node's own TOP stops at { 0 }
a quarter turn apart, the other way separation a half turn — the arrival sits exactly on its BOTTOM, which is the SAME count of 0, taken at the nearer end stops at { 0 }
on one line, either way round separation a quarter turn — this is PARALLEL, and to this machine it is an ordinary angle it walks straight over stops at { quarter }

The two ends see the same relationship from opposite sides: each receives the other's normal, so a square pair reads as separation 0 at one end and a half turn at the other. Both are this machine's halt, which is why it has two.

Why it was a separate file, and why it is not one now

Three attempts at this rule changed the PARALLEL one as a side effect, every time through something that served both: a miss parameterized by which state you were in, a step that took the state as an argument, and a version where a node running neither compared its distance to parallel against its distance to perpendicular to pick a target — parallel arithmetic deciding a perpendicular question.

Two machines in two files had nowhere to put that coupling, and both rules were finished under that arrangement without either disturbing the other. The audit then measured what they had become: one rule, its exact complement, and a single line of genuinely distinct data — which reading counts as HOME.

So the two are now one machine (tiltMachine) and a mode is the ONE COUNT it stops at and nothing else. This is not the fourth attempt at the three above: those parameterized the RULE, and a branch inside a shared miss is what let a change meant for one mode land in the other. Nothing branches on the mode now — settled compares the count against the row and step measures the way up against a quarter turn, and neither can ask whose row it is holding — so the coupling has no place left to live.

The row is one count and not two because the count is taken from the NEARER END of this node's tilt line. Measured from the top, this machine looked like it rested at two separations, 0 and a half turn; those are one reading at the two ends of one line.

Stepping over the other halt

The two halts sit a quarter turn apart in separation, so the walk back to one CROSSES the other. A node that stopped at any halt was taken by whichever it touched first — the log caught it in both directions: a pair holding perpendicular stepped correctly toward separation 0, met a quarter turn on the way, and took up parallel there; a pair holding parallel walked the other way, met a half turn, and took up perpendicular.

So a node halts on ITS OWN halt only. The other one is an angle it passes over, because this machine names no separation but its own two.
