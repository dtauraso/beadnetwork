The lattice

The ring is 24 states, not a number kept in range

The ring is 24 states (tiltState), built once at package init. A tilt IS one of them — Top is a *tiltState, not an int — and turning is following Top.next or Top.prev, a link, never a sum with a wrap to undo. Each state also carries opposite (a half turn away, the bottom tilt) and quarter (a quarter turn on, the coplanar normal), resolved once when the ring is built, so both are field reads rather than sums computed on every use.
next crossing 23 → 0, and prev crossing 0 → 23, are the SAME KIND OF LINK as every other neighbouring pair on the ring — nothing is special at that boundary, because there is no boundary to cross: every state already points at its neighbours, seam or not. There is no twenty-fifth state, so "off the ring" cannot be written down at all.
