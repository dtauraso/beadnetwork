The test and the step

THE TEST what it is source
bottom = mod(top + tau/2, tau) the other end of the tilt line, derived rather than stored bottom
distance = abs(end − arrival), one per end a plain subtraction from each end — nothing folded, nothing minimised distanceTop
offset = +1 / −1 / 0 whichever end is inside a quarter turn names the direction; neither being inside it is the halt offset
THE STEP — what arrived both nodes of a pair — same unmodified rule per machine
this machine.halted(top, arrival) → stand still, reply anyway
otherwise → Top ← this machine.step(top, arrival)
the SETTING mode → already halted at every separation, so an arrival moves nothing; the machine is started at the first arrival (adoptMachine)
The direction and step rows are the one kind's own stepFromVector, run unmodified by both nodes of a pair. There is nothing to dispatch to: the node holds one machine, and which mode it is in supplies the one count the same rule compares against — Categories/NodeKinds/NodePhi/node.go.
