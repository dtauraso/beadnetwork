The test and the step

THE TEST what it is source
sep = |a.idx − b.idx|, folded to ≤ HALF the short way round, so the number means the same thing whichever side the arrival sits on ring.go
c = u if u < HALF, else (b − a) mod points the count from the NEARER END of the tilt line, which is the one measurement the rule makes. It lives on a ring of a half turn nearerEndCount
settled = (c = stop) parallel stops at a quarter. A comparison — no distance is taken and nothing is minimised stoppingCounts
step = next if (stop − c) mod HALF ≤ QUARTER, else prev written ONCE and shared by every mode; the way down is the rest of the circle, so one subtraction settles it. Answerable everywhere on the ring, every halt included step
THE STEP — what arrived both nodes of a pair — same unmodified rule per machine
this machine.halted(top, arrival) → stand still, reply anyway
otherwise → Top ← this machine.step(top, arrival)
the SETTING mode → already halted at every separation, so an arrival moves nothing; the machine is started at the first arrival (adoptMachine)
The direction and step rows are the one kind's own stepFromVector, run unmodified by both nodes of a pair. There is nothing to dispatch to: the node holds one machine, and which mode it is in supplies the one count the same rule compares against — nodes/PairNode/node.go.
