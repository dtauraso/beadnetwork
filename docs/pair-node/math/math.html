One quarter turn, sent as is

Both nodes of a pair run this same unmodified rule — a field read off the ring, nothing further is done to it.

separation, folded to the short side

No trig: both states are already on the ring, so the fold is one subtraction against the ring's own half-turn count (separation). The turn does not read this number: it counts from the NEARER END of the tilt line instead (nearerEndCount), which keeps the end it measured. Separation survives for the one question that is about the two TILTS rather than the arrival — which mode the pair runs (machineForGap) — and there it names no resting state either (Perpendicular).
