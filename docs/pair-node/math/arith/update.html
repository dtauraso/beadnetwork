Whether the tilt goes +1, −1 or stays

distancetopabs(t − a)

distancebottomabs(b − a)

distancetop < 6 : tafter = t + 1

distancebottom < 6 : tafter = t − 1

otherwise : tafter = t the halt

bafter = tafter + 12 (mod 24) — the other end follows, because both are + offset on the same ring

standing still means neither end is inside a quarter turn of a

parallel the normal line: t+6, b+6

tafter, bafter — the two ends after this update. The node stores only the top; the bottom is derived by the same rule wherever it is wanted, so the two cannot come apart

the node runs exactly this: offset returns +1, −1 or 0, and setTop writes mod(t + offset, tau)

which end is acute is the whole of the direction — the top gives +1 and the bottom −1, and neither being acute is the halt

the two distances are plain abs subtractions, so no value here is negative and nothing is folded
