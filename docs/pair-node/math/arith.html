Every number this page uses, and where it comes from

t, a ∈ {0, 1, …, 23}

this node

tilt = t

normal = t + 6

bottom = b = t + 12 (mod 24)

only t moves; the other two are read off it

the partner

tilt = p

normal = p + 6

a = p + 6 a IS the partner's normal — its tilt p is never seen

count from each end of the tilt line up to a

u = t − a (mod 24) from the top

v = b − a (mod 24) from the bottom

which end a is nearer, and its angle

top, c = u if u < 12

bottom, c = v otherwise

the counts differ by 12, so exactly one is under 12 — that end is the nearer one, and its count is the angle

t — this node's tilt, the only thing it stores

b — its bottom, the other end of the same line

p — the partner's tilt, never seen by this node

a — what this node has: the partner's normal

u, v — counts round the ring from the top, and from the bottom, to a

c — the angle at whichever end is nearer, 0…11

worked: t = 11, a = 0, b = 23 → u = 11, v = 23 → top is nearer, c = 11
