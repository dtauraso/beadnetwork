standing still means a lies along one of this node's own two lines

parallel the normal line: t+6, b+6

perpendicular the tilt line: t, b

tafter, bafter — the two ends after this update. Each half moves the end it measured and derives the other, so the ends never have to agree about who moved: one of them is written and the other is read off it

the node stores both ends and runs exactly this: nearerEndCount says which end the count came from, step returns that end moved one slot, and setTop / setBottom write it — each writing the other end off its own opposite in the same statement, which is why the two cannot come apart

read on the nearer end's OWN count the two halves are the same four lines — u under 12 in the first, v under 12 in the second — so no comparison reverses

the reversal appears only if the bottom is measured by the complementary angle, 12 − c, which counts the other way round: then every comparison flips and the two descriptions still pick the same move

the direction is a comparison, not a sign: no value here is negative
