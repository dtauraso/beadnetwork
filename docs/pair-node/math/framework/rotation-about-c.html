A φ turn and a θ turn about C, and the angles seen from O

P = (2, 0, 0), C = (1, 0, 0). P′ = C + polar_to_cart(r, φ + aφ, θ + aθ): φ and θ are two separate rotations of the local vector about C. Both views show the same 3D result.

45° 90°

Front view — x right, y up (the φ tip toward or away from +y shows here)

Top view — x right, z up (the θ swing round the vertical through C shows here)

local: C→P′, the vector turned about C global: O→P before (dashed) and O→P′ after
  1. The local vector from C has its own (r, φ, θ), taken from P − C once.
  2. The φ rotation: φ + aφ. It tips the vector toward or away from +y; θ and r stay.
  3. The θ rotation: θ + aθ. It swings the vector round the vertical through C; φ and r stay.
  4. They are separate — each changes only its own angle, so order does not matter.
  5. P′ = C + polar_to_cart(r, φ + aφ, θ + aθ). The start stays at C; only the end moves.
  6. From O, P′ is read as cart_to_polar(P′ − O). Those global angles are not aφ, aθ.
