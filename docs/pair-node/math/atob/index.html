The a→b and c→b vectors

Node a is at (1, 0, 0) and node c at (0, 0, 1); each vector has r = 1. Each pair is its own global calculation: ba = Ca + polar_to_cart(a→b), bc = Cc + polar_to_cart(c→b).

a→b — its own calculation, in order

    c→b — its own calculation, in order

      1. φ is measured from +y. A φ slider tips its vector over the top and bottom of its node; θ and r stay.
      2. θ is measured round the vertical from +x. A θ slider swings its vector round the vertical through its node; φ and r stay.
      3. The two calculations are independent. ba uses only Ca and a→b; bc uses only Cc and c→b. Neither reads the other's result, so they run in either order, or at once, and give the same numbers.
      4. Each closes its own triangle: O→a + a→b = O→ba, and O→c + c→b = O→bc. Where the two tips meet, both triangles end at the same b.
      5. From O, each b is read as cart_to_polar(b − O). Those angles are not φ and θ, which are about each vector's own node.
