A node holding t and told a turns one slot at a time until it stops. Update rules gives that as two machines and the rule an arrival runs. None of that is needed to say what happens. Given the two numbers you can write down where the node ends and how many arrivals it takes, and the turning in between is arithmetic you never have to watch.

The two numbers, and the one between them

What there is

t is this node's tilt, a is the direction that arrived. Both are counts of slots round a ring of 24, so both are ordinary integers

ℓ is how far apart they are the short way round, so ℓ never exceeds 12

How far it is from stopping

One number, off the quarter

a pair is set up for one of two arrangements, and each stops at its own angle: parallel at the quarter, perpendicular at either end

both are symmetric about the quarter, so q — how far ℓ sits off 6 — settles both, one way up or the other. The two f being complements is the same fact the audit found by drawing them

f is a DISTANCE, in slots, and the next card is what that distance turns out to be worth

The whole run, without running it

Where it stops, and when

f is not only how far off it is — it is the COUNT. Each arrival closes exactly one slot, so f arrivals is the whole run and there is no arrival number f + 1

s is decided once, by which way is closer at the start, and never revisited. The walk cannot turn back, which is why the landing slot is a multiplication and not a simulation

so f = 0 is not a special case or a halt condition — it is the run that takes no arrivals

all three claims are swept over both arrangements and every tilt-against-arrival pair by TestTheWalkIsClosedForm

What this does not say

It holds for a held arrival

a is treated here as fixed. In a live pair it is not: each end sends its own normal and both turn, so a moves while t does. The closed form describes one node against a direction that stays put

that is the honest limit of this page. The exchange itself — two ends, each turning on what the other last sent — is the run on Update rules, and it is why the code keeps the general form (a comparison per arrival) rather than the shortcut above

the arithmetic is still what the machine IS. It is not a model of the machine, and not the machine transcribed: it never mentions a state, and there is nothing in it to step
