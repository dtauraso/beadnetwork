Node 1 vs node 2

Both run the same unmodified code and halt on the same rule: each holds the one machine in one of its chosen modes (perpendicular or parallel), read from the gap at START and carried to the other end on every reply — see machineForGap. Neither halts on the other's separation; it steps straight over it. The one asymmetry is START, which the node numbered 1 owns alone.
