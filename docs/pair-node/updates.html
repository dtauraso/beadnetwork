Derived — pure functions of t, recomputed, never stored

quantity node 1 node 2
top top(t) = t
bottom bot(t) = t + HALF bot(t) = t − HALF
coplanar normal nrm(t) = t + PERP + HALF·(⌊t / HALF⌋ mod 2) nrm(t) = t − PERP
outgoing out(t) = nrm(t) − 2·PERP out(t) = nrm(t) + 2·PERP = t + PERP
angle of index i θ(i) = i · step, from world +y
difference d(a,b) = ((a − b) mod FULL + FULL) mod FULL
acute acute(a,b) ⇔ d < PERP ∨ d > FULL − PERP
perpendicular d ∈ {PERP, FULL − PERP} — NOT acute, and that is the halt
⌊ ⌋ is FLOOR, not Go's /: t < 0 is the common case on node 1 and truncation flips the parity term on the wrong side of 0. d mods TWICE: Go's % keeps the dividend's sign. The parity term is a pure function of t — no crossing flag, no comparison against a previous t.

Both acute tests false only at exact perpendicularity; both true is impossible — top and bot are HALF apart and each acute cone is PERP wide. One step per cycle, so the dial sets |Δt| per unit wall time.
