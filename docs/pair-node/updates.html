Two rules once moved the tilt index — the bead arrival stepped it in this kind's own fixed direction, on top of the acute tests. When they agreed the node double-stepped; when they disagreed it froze. The acute tests are now the only rule that turns a tilt, and the bead is what makes that turn visible and timed.

Each node clears TWICE — once from the button, once when the partner's Reset marker arrives. A single clear each is racy: the partner can place one more bead in the window after this node cleared. The marker-driven clear is ordered after the last thing the partner could have placed, so it is the one that provably lands last.
