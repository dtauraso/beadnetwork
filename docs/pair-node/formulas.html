THE TEST what it is source
sep = |a.idx − b.idx|, folded to ≤ HALF the short way round, so the number means the same thing whichever side the arrival sits on ring.go
miss = min(sep, |sep − HALF|) the PERPENDICULAR machine's own measure. A quarter turn is an ordinary angle to it — one it steps over home = { 0, half }
miss = |sep − QUARTER| the same measure against the PARALLEL home set — and exactly the complement of the one above, the two summing to a quarter turn home = { quarter }
step = next if miss(next) ≤ miss(prev), else prev each machine's own; answerable everywhere on the ring, both halts included perpendicular.go
