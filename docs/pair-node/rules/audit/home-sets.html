What is actually different: which separations count as home

Filled is home, hollow is farthest. Perpendicular's home is exactly parallel's farthest point and the reverse, because quarter is the midpoint of 0 and half — which is why those two misses sum to a constant.

SETTING is the third mode: a node that has not yet decided which of the two it runs. Its home is every separation, so it is already at rest wherever it stands and no arrival moves it — which is what "still being set up" means, said as a home set rather than as an exemption from the rule.
