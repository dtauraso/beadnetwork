The two ties, and which way they break

case why it is a tie what happens
perpendicular, c = a quarter turn its stop, 0, is a quarter turn away going either way round the count-ring turns UP
parallel, c = 0 its stop, a quarter turn, is a quarter away going either way round turns UP
Both fall out of one <= in step: the way up is measured against a quarter turn, and at exactly a quarter the two ways round are the same length, so the ≤ takes it up. It is a convention, not a measurement — there is no better answer, since the two directions are genuinely the same distance. What matters is that it MOVES: standing still at a tie is the freeze the old "not acute" test produced. There are TWO ties and not four: read from the nearer end, each mode has one stop, so each has one count that sits opposite it.
