The whole case space

A node's tilt machine is ONE instance (tiltMachine) whose entire state is whether it has started. So the cases are: two modes, each against every arrival — and what an arrival produces is two distances, one from each end of this node's tilt line, compared against a quarter turn (offset). Nothing else is a case: the turn reads those two numbers and nothing more.

Read a row and you have that mode entirely. SETTING stops at every count, which is why a node being set up cannot be moved by an arrival. PARALLEL stops at ONE count and walks straight through 0. Its row is a single run of ‹ and a single run of ›, because the rule is a single comparison: is the stop within a quarter turn going up.
