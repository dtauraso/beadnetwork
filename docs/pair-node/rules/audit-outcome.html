where perpendicular.go and parallel.go were the same thing — the report that folded them into one machine
The finding The outcome

103 lines, and where they go

step is character-for-character identical, differing only in which miss the receiver resolves to. halted is each machine restating its own miss being zero. String and choice carry nothing but the machine's own identity.

What was done about it

This page was written as a report, not a proposal — the split existed so a change to one file could not move the other, and that property was repeatedly lost when the two shared a parameterised function.

The two are now ONE machine (nodes/PairNode/machine.go), because of what is measured above: the difference is DATA, not code. A mode contributes ONE COUNT and nothing else. The three earlier attempts each parameterised the RULE — a branch inside miss, a mode passed to step — and that branch is what let a change meant for one mode land in the other. There is no such branch now: settled compares the count against the mode's row and step measures the way up against a quarter turn, and neither can ask whose row it is holding.

SINCE THIS PAGE WAS WRITTEN the measurement changed: the rule counts from the NEARER END of the tilt line rather than from the top, so the misses drawn above are no longer computed at all, and a home set of two separations became a single count. The audit's finding holds — the difference between the modes is one line of data — but that line is now shorter than what is drawn here.

The claim the old perpendicular.go header made — that the two share no computation — was true of the TEXT and false of the MATHEMATICS. That is what this page corrected, and the fold is what followed from it.
